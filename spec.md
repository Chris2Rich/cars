# alphahunter
shows compiled ratios for many US companies over time. updated weekly.

# web
shows and displays data in browser - hosted on vercel, gets data from api on request, uses much caching

# api
api has many useful features to make data management easier
api gets the data from file loaded in vps. vps stores data in csv after being created by python.
